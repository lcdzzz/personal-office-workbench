# 工作日志与项目时间线设计

## 目标

新增手写工作日志，使用整月日历作为日志查看入口；日志可关联多个项目，并能从项目进入只包含相关日志的时间线与详情。

## 交互

- 新增“工作日志”导航页，页首显示按周排列的整月日历。
- 日期格不按日志数量使用深浅色；仅以统一、低干扰的标记表示当天存在日志，今天保留独立样式。
- 点击某个日期后显示当天全部日志，可新增、编辑、删除；点击日志条目打开完整正文。
- 日志字段为日期、正文、`projectIds` 多选关联项目、创建/更新时间。不关联项目也允许保存。
- 每张项目卡展示相关日志数量和“查看时间线”入口；时间线按日志日期倒序排列，点击条目查看具体日志详情。

## 数据与兼容

- 本地快照新增 `logs` 数组，服务端新增 `logs.json`，ZIP 备份同步包含该文件。
- 旧的四文件本地数据和 ZIP 备份缺少 `logs.json` 时，读取为 `logs: []`；下次正常保存或导出后自动带上新文件。
- 日志关联已删除项目时，保留日志正文，但在读取时移除失效的项目 ID。

## 边界

- 日志只能手动创建，不会由任务完成或项目状态变化自动生成。
- 日历不展示日志数量热力深浅，不增加时长、标签、附件或评论。
- 一条日志可关联任意多个现存项目，同一日志在每个关联项目的时间线中可见，但本体只有一份。

## 验收

- 能创建、编辑、删除含多项目关联的日志，且保存、刷新、ZIP 导入导出后仍保留。
- 月历能进入指定日期的日志列表，并对有日志日期显示统一标记。
- 项目入口能显示相关日志时间线，时间线条目能打开完整日志。
- 旧数据和旧备份缺少日志文件时仍能正常读取。

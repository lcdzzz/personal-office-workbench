## 授权后的执行与验收

提交上述准确文件，推送 `main` 后先运行三平台候选构建，验收通过再推送 `v1.0.0` 标签。GitHub Actions 先测试，再分别在 Windows x64、Intel Mac、Apple 芯片 Mac 构建并进行两次原生启动验收。必须三个包的核心指纹及提交号一致，才创建非草稿 Release。

发布后下载正式附件，核对 SHA-256、Windows PE / macOS Mach-O 架构，并对正式 Apple 芯片 DMG 再次执行镜像与原生窗口验收。Intel、Windows 在本地尚未构建，最终以对应构建机的原生验收结果为准。

中文 Release 说明见 [v1.0.0.md](v1.0.0.md)。Windows 需要 Microsoft Edge WebView2 Runtime；macOS 为 ad hoc 签名，未做 Developer ID 签名及 Apple 公证，Windows EXE 未做商业代码签名。

## 更新内容

- 待办可关联多个本地文件或目录，并记录成果说明、操作经验。
- 新增「关联文件」页面，按路径汇总关联待办，支持搜索、类型筛选、编辑跳转、复制路径和目录定位。
- 新增统一启动、停止、重启和状态查看脚本；修复 Raycast 从其他目录启动失败的问题。
- Windows、Intel Mac 和 Apple 芯片 Mac 使用同一份界面与业务代码，安装包嵌入版本和核心代码指纹。
- 桌面程序会识别旧版本后台，避免新界面误连旧服务。

## 下载

| 设备 | 附件 |
| --- | --- |
| Windows 10/11 x64 | `Personal-Office-Workbench-Windows-x64-v1.0.0.exe` |
| Intel 芯片 Mac | `Personal-Office-Workbench-macOS-x86_64-v1.0.0.dmg` |
| Apple 芯片 Mac（M 系列） | `Personal-Office-Workbench-macOS-arm64-v1.0.0.dmg` |

Windows：双击 EXE，无需安装 Python。需要 Microsoft Edge WebView2 Runtime；Windows 11 通常已包含此组件，缺少时请从 Microsoft 官方网站安装。

macOS：打开对应芯片的 DMG，将应用拖到 Applications。无需安装 Python。若后台已有旧工作台，请先停止旧服务，再打开新版本。

## 数据与验证

更新前请保存页面中的修改并导出备份。程序仍使用本机应用数据目录，安装包更新不会搬动原数据。关联备份只包含路径和说明，不包含原文件内容。

三个构建均须从原生窗口完成关联、保存、目录定位、备份还原和两次启动的数据保留验证，再发布正式附件。可用 `SHA256SUMS.txt` 核对下载文件。

macOS 使用 ad hoc 签名，未做 Developer ID 签名或 Apple 公证；Windows EXE 未做商业代码签名。系统可能显示首次打开提示。
